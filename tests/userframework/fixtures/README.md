# 真模型的原样输出，留作离线回归

`acme_policy.txt` 是一份结构真实的中文制度（封面、目录、章/条混编、
标题正文同行的条款、附录），`deepseek_acme_reply.json` 是 DeepSeek
2026-08-25 对它的**原样回复**，一个字没改。

**为什么要这个：** 提示词是纯文本，改一个字没有任何东西会红。而 Task 14
实测过，改一个字能让结果从 0/7 变成 7/7——第一版提示词在单元测试里全绿，
在真文档上每一条行号都 +1。

这份固件钉住的是**解析到落库那一段**：拿这份真回复喂进管线，
切出来的七条正文必须逐字等于原文对应行。它管不到提示词本身
（那要真调用），但至少提示词改了之后，管线这一半的回归有人看着。

重新采集：手工跑一次真调用，把 `client.complete()` 的返回原样写进来。
不要手改这个文件——手改过的「真回复」就不是真回复了。
